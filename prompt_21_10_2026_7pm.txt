## 2. Algorithm
### Stage A: Doppler extraction (instantaneous frequency)
- Pluggable `Extractor` interface. Implement (1) STFT ridge tracking with parabolic interpolation and a continuity constraint (Viterbi or smoothed ridge) and (2) a phase-slope estimator (Kay/unwrapped phase over short windows around the coarse ridge); choose automatically, allow manual selection.
- Modes: `tone` (CW) and `fm_center` (carrier of unmodulated/tone-modulated FM = mean instantaneous frequency over an integer number of modulation periods when known, else windows of about 1 s or more).
- Output per window: UTC time stamp (window center), f_d, 1-sigma from an SNR-based CRLB approximation (per-window SNR), quality flag. Robust outlier rejection, low-SNR segment dropping, manual crop/accept/reject, preview spectrogram with the ridge overlaid. Exact time bookkeeping t_n = t_start + n/fs with t_start from SigMF core:datetime / scenario.json (NOT from the file name; the generator records 5 s margins before AOS and after LOS) and verify it against the truth CSV when available.
- Spectral edge note: with a +5 kHz offset and 24 kHz sample rate the FM carrier moves between about -2 kHz (AOS) and -8 kHz (LOS) in baseband and FM sidebands reach the +-12 kHz Nyquist edge near LOS; flag such windows instead of failing; warn near aliasing.
### Stage B: Measurement model
- Predicted Doppler f_d_pred(t; theta) = -f_c * dR/dt / c from SGP4 with the generator's conventions (option for light-time retardation, default consistent with the generator). Build SGP4 states from continuous element values via sgp4init (no TLE-text rounding inside the fit).
- Residual r_k = (f_d_meas_k - b_obs) - f_d_pred_k with per-observation constant frequency bias b_obs (oscillator offset; estimate by default, option to fix to zero; optional linear drift, default off).
- `MeasurementModel` interface returning residuals and weights so other measurements (symbol/timing-rate, SatNOGS waterfall/audio adapters) can be added later; provide the interface and one documented stub only (future ideas of the thesis author).
### Stage C: Nonlinear least squares with SGP4
- Fitted orbit parameters (each free/fixed in config and GUI): mean anomaly, mean motion, RAAN, inclination. Eccentricity, argument of perigee, BSTAR and epoch stay fixed at the input TLE values.
- Parametrize as increments relative to the initial TLE, re-centered at a reference time near the middle of the data (decorrelates mean anomaly and mean motion), with x_scale; convert exactly back to the TLE epoch and verify the corrected TLE and the re-centered solution agree in position across the window (< 1 m).
- scipy.optimize.least_squares (trf; robust loss linear/soft_l1/huber), weights 1/sigma_k, physical bounds, numerical Jacobian with sensible steps, optional weak Tikhonov prior toward the initial TLE with per-parameter prior sigma (default off; effect shown in the report). Seed handling: never let the solver exit at iteration 0 with a large residual (an earlier project had exactly this bug with a 1e-14 seed); retry from perturbed seeds and report the status.
- Initializer for large initial errors: estimate the measured time of closest approach (zero crossing/steepest slope of the Doppler curve) and shift the initial mean anomaly so predicted and measured TCA match; optional multi-start check around the initial guess to expose local minima.
- Convergence diagnostics: iteration log (cost, gradient norm, step norm), termination reason, reduced chi-square, residual RMS in Hz (overall and per observation), rejected outliers. Classify failures: diverged, local minimum, singular/ill-conditioned Jacobian, too few valid samples, suspected time/convention mismatch (residual pattern flips sign).
- Uncertainty and observability: covariance = (J^T W J)^-1 scaled by reduced chi-square; 1-sigma per parameter and in physical units (RTN position uncertainty at the reference time and over the window), correlation matrix, singular values, condition number, a per-parameter observability flag with plain-language warnings and remedies (e.g. "inclination is poorly observable from a single pass; add passes/stations or fix it"). Doppler from one pass mainly constrains the time of closest approach (along-track) and the minimum range/slope (cross-track); report this honestly.
